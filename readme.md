# 🎓 高校课程智能问答系统

基于大语言模型（Qwen/DeepSeek）与检索增强生成（RAG）技术打造的高校课程智能问答助手。系统采用前后端分离架构，融合了**双层意图识别**、**双轨知识库**、**联网搜索**与**多轮对话记忆**，专为大学生、专升本及考研学生提供课程答疑、习题解析和内容总结服务。

## ✨ 核心特性

- 🧠 **双层意图识别引擎**：采用“规则引擎（正则匹配）优先 + LLM 兜底”机制，实现毫秒级意图判断与工具路由（RAG / 联网搜索 / 闲聊）。
- 📚 **双轨 RAG 知识库**：内置公共课程知识库 + 用户专属私有知识库隔离设计，支持 docx/txt/xlsx 多格式解析，特别是 Excel 智能按行重组为自然语言。
- 🌐 **实时联网搜索**：集成 Tavily 搜索 API，针对最新资讯、实时政策等时效性问题自动触发网络检索。
- 💾 **多轮会话记忆**：基于 LangGraph + SQLite 持久化检查点，支持多用户并发下的会话隔离与历史上下文回溯。
- 🔒 **完整鉴权体系**：基于 OAuth2 + JWT 实现用户登录认证，保护接口安全。
- 🎨 **轻量级 Web 交互**：FastAPI 提供高并发后端接口，Gradio 构建极速前端交互，支持聊天框直接上传文件。

## 🛠️ 技术栈

- **后端框架**：FastAPI, Uvicorn
- **AI 框架**：LangChain, LangGraph, LangChain-OpenAI, LangChain-Community
- **向量数据库**：ChromaDB
- **大语言模型**：通义千问, DeepSeek
- **前端界面**：Gradio
- **数据存储**：SQLite, Pandas
- **其他**：PyJWT, Passlib, Tavily, Python-Dotenv
